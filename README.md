# ✅ The Best / Forget Forgetting ToDo List

A cross-platform mobile app built with **React Native**, available on both iOS and Android.

* 📖 Notes
This project is being refactored and updated to the latest versions of React Native and its associated libraries.

This app offers a streamlined, responsive experience for managing to-do lists and notes. Built with **React Native** and powered by **AWS Amplify** and **Amazon Cognito** for secure user authentication, the app features a fully customized UI with intuitive components designed for ease of use.

---

## 🚀 Features
- 🔑 **Full authentication flow** with seamless login and registration  
- 🎨 **Theme-responsive interface** optimized for different screen sizes  
- 📝 **Create, manage, and organize** tasks and notes  
- 📱 **Cross-platform support** (available on **Apple App Store** and **Google Play Store**)

---

## 📦 Installation
Clone the repository and install dependencies:

```bash
git clone https://github.com/<your-username>/forget-forgetting-todo.git
cd forget-forgetting-todo
npm install
```

---

## ▶️ Running the App

To run locally, open **two terminal windows**:

### Terminal 1: Start Metro Bundler
```bash
cd client
npm run start
```

### Terminal 2: Run on iOS
```bash
cd client
npm run ios-default
```
### Terminal 2: Run on android
```bash
cd client
npm run android
```

👉 To specify a simulator:
```bash
npx react-native run-ios --simulator "iPhone 14 Pro"
```
(Replace `"iPhone 14 Pro"` with your preferred simulator model.)
